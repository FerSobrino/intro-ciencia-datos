
1. Abrir una terminal
2. Escribir el siguiente comando, adaptando la ruta para el lugar en el que esté tu llave (por ejemplo, para Windows es diferente)

para macOs o linux:

	ssh -i ~/.ssh/id_rsa TU_USUARIO@bastion.egobiernoytp.io -o ServerAliveInterval=60

para windows:

	ssh -i C:\Users\PROBABLEMENTE_TU_NOMBRE\.ssh\id_rsa TU_USUARIO@bastion.egobiernoytp.io -o ServerAliveInterval=60

3. Escribir el siguiente comando, es para que Python se inicialice correctamente:

	PYTHONPATH=$PWD

---------------------------------

SOLO LA PRIMERA VEZ crear el virtualenv para la clase on el siguiente comando:

	virtualenv claseccd

---------------------------------

4. Activar el virtualenv de la clase con el siguiente comando:

	source TC4025/bin/activate

---------------------------------

SOLO LA PRIMERA VEZ instalar los siguientes paquetes con los siguientes comandos (corre uno por uno):

	pip install pandas

	pip install notebook

---------------------------------

SOLO LA PRIMERA VEZ clonar el repositorio de gitlab en tu bastion:

	git clone https://gitlab.com/egobiernoytp/Clases/Ciencia-de-datos/intro-ciencia-datos.git

Te va a pedir tu nombre de usuario y contraseña de gitlab.

---------------------------------

5. Actualiza todo el material nuevo que los profesores hayan agregado al repositorio de gitlab:

	git pull

6. Abrir un jupyter notebook, especificando el puerto en el cual se abrirá la conexión, con el sigueinte comando. Es muy importante que uses solamente el puerto que te fue asignado.

	jupyter notebook --port XXXXX

7. A la par, en otra terminal *en tu computadora*, abrir el puerto de tu computadora, para poder conectarla directamente a bastion. Usa el mismo puerto.

	ssh -i ~/.ssh/id_rsa -NL localhost:XXXXX:localhost:XXXXX TU_USUARIO@bastion.egobiernoytp.io
